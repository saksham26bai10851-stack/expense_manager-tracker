# Expense Tracker using Python

## Overview

Expense Tracker is a command-line Python application that helps users manage their daily expenses.

The application allows users to add, view, search, and delete expenses. It also provides a simple report showing total expenses, highest expense, and lowest expense.

Expense data is stored locally in a JSON file.

## Features

* Add a new expense
* View all expenses
* Search expense by ID
* Delete an expense
* Generate expense report
* Input validation
* Error handling
* JSON-based data storage

## Technologies Used

* Python 3
* JSON
* VS Code
* Git and GitHub
* Python Standard Library
