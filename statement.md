# Project Statement

## Project Title

**Expense Tracker using Python**

## 1. Problem Statement

Managing daily expenses manually can make it difficult to keep track of how much money is being spent. When expenses are recorded in different places, it can become difficult to search, update, or review them.

The **Expense Tracker** is a command-line Python application designed to provide a simple way to record and manage daily expenses. The application allows users to add expenses, view saved expenses, search for a particular expense, delete an expense, and generate a basic expense report.

The project uses Python concepts such as functions, classes, lists, dictionaries, file handling, JSON storage, exception handling, and modular programming.

## 2. Project Scope

The project focuses on managing personal expense records through a command-line interface.

The system provides the following functionality:

* Add a new expense
* View all recorded expenses
* Search for an expense using its ID
* Delete an existing expense
* Generate a summary report
* Store expense data locally using a JSON file
* Validate user input and handle common errors

The project is intended as a learning-oriented Python application and does not include online payments, banking integration, or real-time financial services.

## 3. Target Users

The intended users are:

* Students who want to track daily spending
* Individuals who want a simple personal expense record
* Beginners learning Python programming
* Users who prefer a lightweight command-line application

## 4. High-Level Features

### 4.1 Expense Management

Users can add and store expense information such as the expense name and amount.

### 4.2 Expense Viewing

Users can view all currently stored expenses along with their IDs and details.

### 4.3 Expense Search

Users can search for a specific expense using its unique expense ID.

### 4.4 Expense Deletion

Users can delete an existing expense using its ID.

### 4.5 Expense Report

The system generates a basic report containing:

* Number of expenses
* Total amount spent
* Highest expense
* Lowest expense

### 4.6 Data Storage

Expense records are stored locally in a JSON file so that the data can be used again when the application is restarted.

### 4.7 Input Validation and Error Handling

The application checks user input and handles common errors such as invalid numbers, invalid expense IDs, empty input, and incorrect menu choices.

## 5. Project Objectives

The main objectives of this project are:

1. To develop a functional expense management application using Python.
2. To apply Python programming concepts in a practical project.
3. To implement modular and maintainable code.
4. To provide basic data persistence using JSON.
5. To implement input validation and error handling.
6. To provide a simple reporting feature for expense analysis.
7. To demonstrate basic testing of the application.

## 6. Expected Outcome

The expected outcome is a working command-line Expense Tracker that allows users to manage expense records efficiently and generate a simple summary of their spending.

The project also demonstrates the practical use of Python programming concepts covered in the Python Essentials course.
